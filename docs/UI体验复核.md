# UI 重写「体验目标」复核（2026-10-19）

> 复核方式：用测试库（29410）注入 4~9 月共 600+ 条记录 + 14 人 + 5 工种，
> 在 1366×768 / 1440×900 / 1536×864 / 1920×1080 四个宽度下逐页截图并做 DOM 测量。
> 开发库（29401）**未做任何写操作**。截图在 `logs/ui-audit/`。

## 一、结论

**视觉一致性：达标。核心页的「首屏可用性」：未达标。**

重写解决了"看起来不像一个产品"的问题，但评估报告里排第一的那条——
「签到页一屏内 20 个元素平铺、主操作要滚动才看得到」——**没有真正解决，只是从"平铺"变成了"两栏里左栏过高"**。

关键数据（1366×768，签到页）：

| 元素 | 位置 | 是否首屏可见 |
|---|---|---|
| 「录入」主按钮 | top 788 / bottom 828 | ❌ 在 768 视口下方 20px |
| 「当天汇总」条 | top 853 | ❌ 完全不可见 |
| 当天记录表 | 84~735 | ✅ |

验收标准原文是「1366×768 下首屏同时看到录入按钮和当天记录前 3 行」——**这条没过**。
1536×864 下按钮 bottom 828，只剩 36px 余量；只有 1440×900 及以上才真正舒服。

## 二、确实做到的（值得保留）

1. **视觉统一**：token 层（色/圆角/阴影/字号）落地，卡片、表头、按钮、分页器全站一致，不再有 `bg-gray-50` 与 antd 底色打架。
2. **两栏布局方向正确**：1536 以上录入与记录同屏，不再来回滚动；1366 下右栏表格也没有横向溢出（实测 `overflow=0`）。
3. **交互细节补齐**：快捷工时 chip 有选中态、日期有「今天/昨天」、±分钟降级为 text 按钮、人员下拉有提交前预览。
4. **噪音收敛有效**：`Alert` 从 31 处降到 20 处代码级、首屏常驻只剩 1 个；说明文案压成一行小字。
5. **数字排版**：`tabular-nums` 生效，工时/金额纵向对齐。
6. **加载态/空态起步**：骨架屏替代全屏 Spin，签到页空态带操作指引。

## 三、没做到 / 新引入的问题

### P0 — 直接影响"每天要用"的体验

**1. 主按钮在折叠线以下（1366×768）**
`src/pages/qian-dao/BatchEntryPanel.tsx:121-160`
根因是三块叠加：`本次录入` 预览块固定 `minHeight: 130` + 常驻 Alert 约 40px + 快捷工时两行 120px。
左栏总高 878px，视口可用高度 684px，**溢出 194px**。
建议：预览块压成一行（`3 人 · 8 小时 · 砌墙`），或挪到「录入」按钮下方；Alert 不再常驻。

**2. 首屏就弹黄色警告「请选择考勤人员」**
`useBatchEntry.tsx:120-125` + `BatchEntryPanel.tsx:254-259`
空表单一进来就是 warning 色 Alert，读起来像"出错了"。应改为中性提示，或只在点过「录入」之后出现。

**3. 「当天汇总」被放在左栏最底部**
`BatchEntryPanel.tsx:275-276`
它的作用是"这人今天是不是已经记过了"，恰恰是录入时最该看的信息，现在 1366/1536 下都在折叠线以下。
建议移到右栏「当天记录」卡片头部（`当天记录 · 9人/10条/67h`）。

**4. ID 列（nanoid）是 5 个列表页的第一列且最宽**
`workers/list.tsx`、`workType/list.tsx`、`xin-zi/list.tsx`、`gong-shi/list_table.tsx:243`（width 130~200）
`5go3h8pqhmlz5ar` 这类 ID 对个人使用毫无意义，却把「姓名」「工种」挤到视觉中段。
建议：默认隐藏（操作列加「⋯ → 复制 ID」），或移到最后一列；同步改 E2E 的 `row-id-*` 断言。

**5. 工时&薪资页默认范围无数据时，页面像坏了**
`stores/index.ts:49-52` 默认 `[本月, 下月]`；数据不在范围内时，14 行全是 `--` 和 `0`，没有任何说明。
建议：范围内 0 条时给 `EmptyState`（「当前范围 2026-10 ~ 2026-11 无记录」+「跳到最近有数据的月份」按钮）。

**6. 同一个数三种写法（缺单位）**
- 签到页工时列：`8`（无单位）
- 签到页汇总/预览：`67h`、`8 小时`
- 工时&薪资合计：`272`、薪资 `3970`（连"元"都没有）
建议：表格列头写「工时(h)」「薪资(元)」，或统一 `formatHoursExact` 输出带单位。

### P2 — 图表与统计页

**13. 每日趋势图在稀疏数据下变成「条形码」**
`tong-ji/options.ts:41-95`：`connectNulls:false` + `type:"time"` + 180 天跨度 → 相邻有数据的两天之间被 null 断开，每段只剩 1 天宽度，画出来是一排竖线，完全看不出趋势（见 `14-tongji-overview-full.png`）。
同时 `dataZoom` 滑块是一条几乎看不见的浅蓝条。
建议：稀疏时 `showSymbol:true` + 空心点，或按周聚合，或 `connectNulls:true` 并给断点标记。

**14. 个人分析 Tab 的指标是纯文本**，与概览/时间的 `StatCard` 不一致；左右两栏把折线图压到约 260px，x 轴标签被迫斜排。

**15. 工时&薪资展开表**：子表重复「工人」列（父行已显示姓名）、内部还嵌了分页器、列与父表不对齐。

**16. 列宽不随内容调整**：1366 下「工时」列 158px 放一个 `8`，而「人员姓名」只有 135px。

## 四、建议的下一步（按性价比排序）

**第一批（约 2~3 小时，收益最大）**
1. 签到页首屏：预览块压成一行 + Alert 非常驻 + 当天汇总移到右栏表头 → 主按钮回到 768 以内。
2. 去掉/后置 ID 列（5 个页面），同步 E2E。
3. `--warning` 补进 `:root`；编辑行加 `rowClassName` 浅蓝底。
4. 工时&薪资/考勤记录：范围为空时给 `EmptyState`，表头补单位。

**第二批（约 2 小时）**
5. 删除按钮默认中性、hover 变红；空态统一到 `EmptyState`；移除 disabled 的「添加记录」。
6. 帮助抽屉改成「分组 + 列表」结构，修掉「0、」和重复条目。

**第三批（约 2 小时）**
7. 每日趋势图稀疏数据处理（`showSymbol` / 周聚合）。
8. 个人分析 Tab 指标卡统一；展开表去掉重复列与嵌套分页。

> 第一批做完，「重写 UI 是为了用户体验」这个目标才算真正落地；第二批是收口；第三批是锦上添花。

## 五、修复记录（2026-10-20 已全部实施）

三批建议已全部落地，`tsc` 仅剩既有 `filters.ts` 错误，`lint 0`，单测 226 passed，E2E 见下。

### 签到页（P0）

| 改动 | 结果 |
|---|---|
| 字段顺序改为 日期 → 工种 → 工时 → 人员 → 录入 | 日期/工种/工时常连续复用，人员才是每次要改的，紧挨按钮少走鼠标；多选下拉只盖住预览与按钮，不再挡必填项 |
| 「本次录入」130px 预览块压成一行 | 高度 130 → 20 |
| 整块 `Alert` 改为一行状态文字 | 未选人/未选工种用中性灰（不再一进页面就黄色告警），合并/超限/失败才用彩色；高度 40 → 20 |
| 「当天汇总」从左栏底部移到右栏记录表上方 | 1366×768 下 top 853（不可见）→ 219（可见） |
| 人员下拉改为朝下展开（`listHeight` 180 → 140） | 原来放不下会翻转到上方、盖住工时输入与快捷按钮；现在只盖住「本次录入」预览和录入按钮，日期/工种/工时全程可见 |
| **主按钮位置** | top 788 / bottom 828 → **top 649 / bottom 689**（768 视口内，余量 79px） |

### 列表页与详情（P0/P1）

- **ID 列**：5 个页面 130~200px → 96px，灰字等宽（`.id-col`），并把「姓名」列改为不设宽度吸收剩余空间，ID 不再被等比放大。
- **单位统一**：`工时(h)` / `合计工时(h)` / `合计薪资(元)` / `时薪(元/时)` / `总工时(h)`；薪资设置里默认条目的工人列由空白改为「全部人员（默认）」。
- **工时&薪资空范围**：新增「2026-10 ~ 2026-11 内没有考勤记录 + 跳到最近有记录的 2026-09」提示，不再满屏 `-- / 0`。
- **行内编辑**：`row-editing` 整行浅蓝底 + 左侧 3px 品牌色条。
- **删除按钮**：默认中性灰，hover 变红（`.danger-hover`），不再整表一排红字。
- **空态**：人员/工作/薪资/考勤记录四页统一 `EmptyState`（带标题 + 说明）。
- **变量补齐**：`:root` 补 `--success/--warning/--error/--info/--bg-hover/--radius-sm`，未定价提示恢复警示色。
- **帮助抽屉**：改为「小节标题 + 有序列表」，修掉从「0、」开始与第 4/5 条重复；宽度 480。
- **考勤记录**：disabled 的「添加记录」降级为 text 按钮（E2E 仍要求它可见且 disabled）。

### 统计页（P2）

- **每日趋势**：`showSymbol` 在 ≤200 天时显示数据点，孤立出勤日不再退化成"条形码"；`dataZoom` 滑块补底色/填充/手柄样式。
- **个人分析**：6 个指标从裸 `Statistic` 换成 `StatCard`，与概览/时间 Tab 一致。
- **展开表**：日表去掉嵌套分页器；「工人」列压窄到 90px（展开多人时仍能认出归属，不再占据主视觉）；三张表补单位。
